# Engineering FlowCommerce

Este repositório acompanha a série **Engineering FlowCommerce** no LinkedIn.

A série demonstra como funcionalidades complexas de software podem ser entendidas, validadas e preparadas **antes de a implementação começar**.

A FlowCommerce é uma plataforma SaaS B2B fictícia usada como um estudo de caso de engenharia realista. Cada episódio parte de uma solicitação de negócio e percorre um processo de detalhamento de atividade estruturado.

O foco é o raciocínio de engenharia — não o código.

## O que você vai encontrar aqui

Conforme a série avança, este repositório vai publicar parte dos resultados produzidos antes da implementação, como:

* catálogos de requisitos
* diagramas de arquitetura e fluxo
* contratos de integração e dados
* riscos, perguntas em aberto e avaliações de prontidão

Os resultados são adicionados **parte por parte**, alinhados a cada post no LinkedIn.

## Estrutura da série

Cada episódio é dividido em partes. Cada parte tem sua própria pasta e README.

```text
episode_1/
  part_1/
  part_2/
  ...
episode_2/
  ...
```


## Como acompanhar

1. Leia o post no LinkedIn para a narrativa de engenharia.
2. Abra a pasta correspondente de episódio/parte neste repositório para os resultados detalhados.
3. Use o README de cada parte como guia do que ler e em que ordem.
